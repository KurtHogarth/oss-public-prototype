# OSS Public Prototype

**Operating System of Society** — a static multi-page prototype, not a production system.

## Purpose

A browsable sketch of constitutional, anti-concentration institutional design: the state as a service with explicit invariants, not an inherited fate.

## Modules

| Module | Role |
|--------|------|
| Core | Constitutional kernel, Genesis consent, three-sphere anti-concentration |
| Economy | Geolibertarian framing, LVT sketch, calculator demo |
| Accountability | Observation vs enforcement separation |
| Civic layer (Polis MVP) | Sentiment map, no reply threads, group-aware consensus style |
| Court MVP | Category paths, human ratification gate before publish |
| Public memory | Network + time sketch, opinion-map hooks |
| Social rating | Visual metrics for **companies and public / social figures** (district → government) — demo only |
| Open questions | Honest registry of residual risks |

Languages: **English (default)**, Ukrainian, Russian. Light / dark theme.

## Design stance

- **Rating ≠ enforcement** — scores inform; they do not auto-sanction.
- **Human ratification gate** — machines may propose; binding publication requires a human step.
- **Three spheres** — adjudication, data, and finance are not held by one institution.
- **Exit / Voice / Loyalty** — fork right, civic signal layer, conscious Genesis.
- **Honest open risks** — metric gaming, custody/nominees, standard drift, weak Sybil in MVP remain listed.
